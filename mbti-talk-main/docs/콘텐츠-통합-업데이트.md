# MBTI TALK 콘텐츠 통합 업데이트

작성일: 2026-11-13

## 반영 기준

- 16개 유형별 답장 지연 행동과 8개 유형의 연락 스타일은 사용자가 이전에 제공한 개발 지시서에서 가져왔다.
- 아래 카카오톡 문장은 해당 행동 설명을 바탕으로 새로 다듬은 예시다. 원문 인용이나 특정 성격에 대한 단정이 아니다.
- 전달받은 네이버 블로그 글은 이 환경에서 페이지 접근이 차단되어 검토할 수 없었다. 따라서 해당 글의 내용이 이 자료에 포함된 것처럼 표기하지 않는다.
- 사이트의 10개 상황별 기본 문장과 대화 접근법은 계속 공통 템플릿으로 제공한다. 답장 지연 상황은 16개 유형별 문장 3가지 말투를 제공하며, 일상 대화는 연락 스타일을 제공받은 8개 유형에 한해 별도 문장을 제공한다.

## 답장이 늦거나 연락이 없을 때

| 유형 | 기존에 제공된 행동 경향 | 자연스럽게 보낼 문장 |
|---|---|---|
| ISTJ | 약속 장소·날짜·시간을 확인하고 빠진 내용을 다시 묻는다. | 일정 확인하려고 연락했어. 장소나 시간 바뀐 게 있으면 알려줘. |
| ISFJ | 메시지를 보낸 시각과 상대가 바쁜 상황인지 생각한다. | 요즘 바쁜가 봐. 급한 건 아니니까 괜찮을 때 답해 줘. |
| INFJ | 최근 대화와 과거에 반복된 패턴을 생각한다. | 요즘 대화가 뜸해서 안부가 궁금했어. 혹시 무슨 일 있는 건 아니지? |
| INTJ | 답이 급한지 판단하고 기다릴 수 있으면 대화창을 닫는다. | 급한 건 아니야. 내일까지 편할 때 답해 줘. |
| ISTP | 급한 일이면 전화하고, 안부라면 하던 일을 이어간다. | 급한 일이면 전화할게. 안부라면 편할 때 답 줘. |
| ISFP | 사진에 답이 없으면 머쓱해하고 다음 말을 망설인다. | 이 사진 보니까 네 생각나서 보냈어. 시간 날 때 봐줘 🙂 |
| INFP | 보낸 메시지와 이모티콘을 다시 확인한다. | 내가 보낸 말이 혹시 부담스럽진 않았을까 궁금했어. 천천히 답해도 괜찮아. |
| INTP | 마지막 문장을 확인하고 상대가 대화가 끝났다고 여겼을 가능성을 생각한다. | 혹시 앞 메시지 확인했어? 답이 급한 건 아니니까 편할 때 봐줘. |
| ESTP | 답을 기다리기보다 자신의 일정을 먼저 정한다. | 나는 일정을 먼저 정해둘게. 가능하면 오늘 알려줘! |
| ESFP | 영상에 반응이 없으면 크게 의미를 두지 않고 다른 친구에게도 공유한다. | 이 영상 보자마자 네 생각났어ㅋㅋ 시간 날 때 봐줘! |
| ENFP | 새 이야기를 보내려다 이전 메시지에 답이 없으면 잠시 멈춘다. | 새 얘기 생각나서 연락했어! 지난번 메시지는 편할 때 답해도 돼. |
| ENTP | 농담을 더 보낼지 고민하다 다음에 직접 이야기하기로 한다. | 한마디 더 보낼까 하다가 멈췄어. 다음에 만나서 얘기하자 😄 |
| ESTJ | 예약 마감 전 답변 기한을 확인하고 대안을 정한다. | 예약 때문에 오늘 답이 필요해. 어려우면 알려줘, 다른 방법 알아볼게. |
| ESFJ | 이전 농담이 마음에 걸렸는지 다음 만남에서 살핀다. | 지난번 대화가 혹시 마음에 걸렸어? 편할 때 이야기해 줘. |
| ENFJ | 상대가 힘들다고 했던 점을 기억하고 안부를 묻는다. | 전에 힘들다고 했던 일은 좀 괜찮아졌어? 네 생각나서 안부 물어봐. |
| ENTJ | 일정 관련 답이 없으면 선택지를 좁혀 다시 묻는다. | 일정 때문에 확인할게. 금요일과 토요일 중 언제 가능해? |

사이트 코드에는 위 16개 유형 모두 자연스럽게·다정하게·간결하게의 3가지 말투가 들어 있다. 표는 자연스럽게 말투의 검토용 기준 문장이다.

## 사이트에 반영된 상황별 구성

1. 답장이 늦거나 연락이 없을 때: 16개 유형별 행동 설명 및 3가지 말투 문장.
2. 일상적인 대화를 이어가고 싶을 때: 연락 스타일을 제공받은 8개 유형의 3가지 말투 문장, 그 외 유형은 공통 문장.
3. 나머지 8개 상황: 공통 접근법과 자연스럽게·다정하게·간결하게 기본 문장.
4. 추천 문장은 결과 화면에서 직접 수정하고 복사할 수 있다.
5. MBTI 설명은 참고로만 사용하고 개인차가 있음을 안내한다.

## 두 사람 MBTI 상호작용

- 사용자 MBTI와 상대방 MBTI를 각각 선택한다. 상대방 선택 목록에서는 사용자와 같은 유형을 제외한다.
- 두 사람의 E/I, S/N, T/F, J/P 선호를 상황별 우선순위로 비교해 대화 속도, 구체성, 감정 표현, 일정 확정 방식에 관한 상호작용 안내를 만든다.
- 실제 문장은 선택한 상황과 말투에 더해 두 유형의 선호를 참고해 생성한다. 예: 고민을 들어줄 때 상대가 F면 감정을 먼저 묻고, T면 함께 정리할 문제나 해결 방향을 제안한다.
- 카카오톡 공유 링크에도 두 유형과 선택 상황을 넣어 같은 조합을 열 수 있게 한다.
- 선택한 두 유형이 번갈아 말하는 2턴 대화 예시를 제공한다. 약속·만남 상황에는 사용자가 제시한 데이트 동선과 꼭 가고 싶은 카페의 조율 사례를 포함한다. 사용자는 동선 제안자/카페 제안자 역할을 선택할 수 있고, 보내기 문장은 선택한 역할의 발화와 일치한다. 말투 선택도 대화 예시에 반영한다.
- 이는 MBTI 지표를 이용한 안내 규칙이며, 16×15×10×3개 조합을 사람 손으로 각각 검수한 데이터는 아니다. MBTI를 고정된 성격 판정으로 취급하지 않는 안내를 함께 제공한다.

## 인터넷 공개 자료에서 추가한 카톡 스타일 요약

인터넷 MBTI 카톡 글에서 반복되는 묘사를 16개 유형 참고 프로필로 새로 요약해 코드에 추가했다. 요약 축은 답장 길이·템포, 안부 표현, 구체적인 일정 전달, 아이디어·농담·사진 공유 같은 대화 소재다. 이 프로필은 `src/data/guides.ts`의 `onlineChatProfiles`에 있고, 상대 MBTI 선택 시 상호작용 설명에 나타난다.

문장 생성에는 유형을 고정 라벨로 쓰기보다, 상대의 선호를 상황에 맞게 반영한다. 예를 들어 고민 상담은 상대 T/F에 따라 함께 정리할지 마음을 먼저 들을지 문장을 바꾸고, 약속 잡기는 상대의 S/N·J/P에 따라 장소·시간을 구체화하거나 유연한 선택지를 둔다. 답장 지연은 사용자가 이전에 제공한 유형별 행동 경향을 우선 사용한다.

### 참고 및 적용 한계

- [MBTI Type Guide — How Every MBTI Type Texts](https://mbtitypeguide.com/en/psychology/how-every-mbti-type-texts): 16유형 문자 습관을 유머러스한 유형 묘사로 소개한다. 원문 표현을 가져오지 않고 공통적인 묘사만 다시 요약했다.
- [Truity — How Your Texting Habits Reveal Your Personality](https://www.truity.com/blog/how-your-texting-habits-reveal-your-personality): 16개 유형별 메시지 습관과 이모지·문장 길이 묘사를 교차 참고했다. 이 역시 일반적인 온라인 유형 콘텐츠로 취급한다.
- [16Personalities — From Miscommunication to Effective Team Communication](https://www.16personalities.com/articles/from-miscommunication-to-effective-team-communication-insights-into-every-personality-type): 유형별 의사소통 강점과 오해 가능성, 사람마다 다른 경향이라는 주의점을 참고했다.
- [The Myers-Briggs Company — Communication Style Report](https://asia.themyersbriggs.com/wp-content/uploads/2016/09/8.FormM-Communication-Style-Report-NEW.pdf): E/I·S/N·T/F·J/P의 기본 선호를 참고했다. 보고서도 선호는 능력이나 고정된 행동이 아니며 누구나 반대 선호를 사용할 수 있다고 설명한다.
- [Microsoft Research — Style and Alignment in Information-Seeking Conversation](https://www.microsoft.com/en-us/research/publication/style-and-alignment-in-information-seeking-conversation/): 대화 스타일에 한 가지 최선은 없고 상호작용 중 스타일 정렬이 나타날 수 있다는 결과를 참고해, 상대에게 일방적으로 맞추기보다 서로의 속도와 정보 방식을 조정하는 가이드를 추가했다.

카톡 스타일 인터넷 글은 대부분 유머와 공감을 위한 유형화다. MBTI 자체나 각 유형별 문자 습관이 보편적으로 입증됐다는 뜻으로 소개하지 않는다. 사이트 문장은 실제 관계와 상황에 맞춰 수정할 수 있도록 계속 편집 가능하게 둔다.

이 데이터는 160개 유형·상황 조합을 모두 개별 조사·검수한 완성본은 아니다. 확인된 사용자 제공 자료와 공통 템플릿을 구분해 보여준다.
