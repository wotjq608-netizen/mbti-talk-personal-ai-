# MBTI TALK

MBTI와 대화 상황을 골라 바로 써볼 문장과 대화 가이드를 확인하는 웹 MVP입니다.

## 시작하기

Node.js 20.9 이상이 필요합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. MBTI와 상황을 선택하고, 세 가지 말투를 바꾸거나 추천 문장을 복사할 수 있습니다.

## 현재 범위

- 내 MBTI와 상대 MBTI를 각각 선택해 서로 다른 유형 조합으로 대화 가이드 생성
- 10개 대화 상황 및 자연스럽게 / 다정하게 / 간결하게 말투 선택
- 결과 안내, 대화 접근법, 카카오톡 문장, 추가 문장, 주의점
- 자연스럽게 / 다정하게 / 간결하게 말투 선택
- 클립보드 복사 및 모바일 대응 레이아웃
- Kakao Share 버튼 준비 및 `/api/kakao/skill` 채널 챗봇 엔드포인트
- 답장이 늦는 상황에 대한 16개 유형별 행동 설명과 3가지 말투 반영
- 두 사람의 E/I, S/N, T/F, J/P 선호를 상황에 맞춰 조합하는 상호작용 문장 규칙
- 약속·만남 상황의 데이트 동선/카페 2턴 대화 예시 및 기타 상황의 유형별 대화 예시
- 공개 MBTI 카톡 자료 요약을 참고 프로필로 표시하고 출처 링크 제공

상대 유형과 상황에 따른 문장은 조합 규칙으로 생성합니다. 모든 유형 쌍과 상황을 각각 별도로 작성·검수한 완성 콘텐츠는 아니므로, MBTI를 참고 정보로 안내하고 사용자가 문장을 직접 수정할 수 있게 합니다. 계정, 저장, 결제 등은 별도 범위입니다.

카카오 공유와 챗봇 스킬/GitHub→Render 배포 절차는 [`docs/integrations-and-deployment.md`](docs/integrations-and-deployment.md)에 있고, Render Blueprint 설정은 `render.yaml`에 있습니다. 실제 카카오 앱 키, 채널·챗봇 설정, GitHub/Render 계정 및 공개 도메인은 아직 연결되지 않았습니다.

## 명령

- `npm run dev` 개발 서버
- `npm run build` 배포용 빌드
- `npm run lint` 코드 점검
